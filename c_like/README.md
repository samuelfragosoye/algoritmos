Este repositório contém as soluções para o problema **"Prêmio"** da Olimpíada Brasileira de Informática (OBI 2023 - Fase 1, Nível Júnior), implementado em 5 linguagens de programação diferentes.

Este projeto foi desenvolvido como parte da disciplina de **Algoritmos e Estruturas de Dados**.

## 📄 Descrição do Problema

O objetivo é calcular qual prêmio os colaboradores de uma ONG merecem com base na pontuação de vendas de produtos:
- **Pão:** 1 ponto
- **Doce:** 2 pontos
- **Bolo:** 3 pontos

**Regras de Premiação:**
- Pontuação $\ge$ 150: **Bolo** (B)
- Pontuação $\ge$ 120: **Doce** (D)
- Pontuação $\ge$ 100: **Pão** (P)
- Pontuação < 100: **Nenhum** (N)

## 🚀 Funcionalidades

Todas as implementações seguem os seguintes requisitos acadêmicos:
- ✅ **Entrada e Saída de Dados:** Interação via terminal.
- ✅ **Estruturas de Seleção:** Uso de `if`, `else if`, `else`.
- ✅ **Estrutura de Repetição:** Implementação de loop (`do-while` ou `while`) para permitir múltiplos cálculos em uma única execução.
